# GPT-Voyager 1.8.1

发布日期：2026-08-05

## 本次更新

- 在新对话打开后立即发送消息时，ChatGPT 会先使用临时对话地址，再切换到正式对话页面。Timeline 现在会自动重新绑定当前对话，圆点无需刷新即可恢复，并继续随新消息实时更新。
- ChatGPT 延迟完成页面加载并替换页面节点时，Prompt Manager 悬浮球和面板会自动重新挂载，不再出现先显示后消失、只能刷新恢复的情况。

## 安装

下载 `chatgpt-voyager-1.8.1-chrome.zip`，解压后在 `chrome://extensions` 打开开发者模式，选择“加载已解压的扩展程序”。

Chrome / Edge 商店版预计在 **2026 年 8 月 8 日前**通过审核；审核期间可先使用 GitHub 版本。

---

## What's new

- When a message is sent immediately after opening a new chat, ChatGPT first uses a temporary conversation route and then switches to the final conversation page. Timeline now rebinds automatically, restores its dots without a refresh, and continues updating as new turns appear.
- If ChatGPT completes a late hydration pass and replaces page nodes, the Prompt Manager floating button and panel automatically remount instead of disappearing until the page is refreshed.

## Installation

Download `chatgpt-voyager-1.8.1-chrome.zip`, extract it, open `chrome://extensions`, enable Developer Mode, and choose **Load unpacked**.

The Chrome / Edge store build is expected to pass review by **August 8, 2026**. The GitHub build is available while review is in progress.
